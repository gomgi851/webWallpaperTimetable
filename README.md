# 나만의 시간표 배경 생성기

React + Vite 기반의 현대적인 시간표 배경 생성 웹 애플리케이션입니다.

**버전:** v1.1.3

## ✨ 주요 기능

- 📸 배경 이미지 업로드
- 🖼️ 다양한 해상도 지원 (FHD, QHD, UHD, 커스텀)
- 🎨 텍스트 색상 선택 (흰색, 검은색)
- 📍 시간표 위치 조정 (가로/세로)
- 📏 크기 조절 (가로/세로 비율)
- 📚 시간표 데이터 입력 (요일, 강의명, 시간, 강의실)
- 🎭 뉴모피즘 디자인 UI
- 🖱️ 실시간 Canvas 렌더링
- ⬇️ PNG 이미지로 다운로드
- 🌐 반응형 디자인 (PC, 태블릿, 모바일)

## 💻 사용법

1. 웹 애플리케이션 접속
2. 배경이 될 이미지 선택
3. 원하는 설정 조정
   - 해상도 선택
   - 텍스트 색상 설정
   - 시간표 위치 및 크기 조절
4. 수업 정보 입력
   - 요일, 강의명, 시간, 강의실 입력
   - 추가 버튼으로 여러 강의 등록
5. "배경화면 생성하기" 클릭
6. 생성된 이미지 다운로드 또는 새 탭에서 열기

## 시간표 사진에서 가져오기 (v1.1.2)

`2. 수업 정보 입력`에서 **시간표 사진에서 가져오기** 오른쪽의 **파일 선택**을 누릅니다.

1. 에브리타임 PNG/JPG/WEBP 사진을 선택하면 자동으로 인식을 시작합니다.
2. 진행률 바가 100%에 도달하면 인식 가능한 수업 4개 이상일 때 기존 시간표 전체를 자동 교체합니다.
3. 4개 미만이면 수동 입력을 안내하는 오류 창을 표시하며 기존 목록을 유지합니다. 인식 가능한 수업은 과목명·월~일 요일·유효한 시작/종료 시각이 있는 수업입니다. OCR 철자의 정확성을 보장하는 기준은 아닙니다.
4. 사진의 월~금·월~토·월~일 열 수를 자동 구분합니다. 시작/종료 시각은 실제 시간 눈금 사이의 위치에서 계산해 5분 단위로 반올림하므로 10분·15분 단위 수업도 처리합니다. 표 전체가 나온 사진을 사용해주세요.
5. 수업 입력에서 토·일을 선택할 수 있으며, 배경 출력은 평일 수업만 있으면 5열, 토요일 수업이 있으면 6열, 일요일 수업이 있으면 7열로 생성합니다.

하단에 따로 표시된 시간 미지정 사이버강의는 제외합니다. 자동 반영 후 아래 기존 수업 입력칸에서 수정할 수 있습니다. 개발용 사진 선택 버튼과 원문 검토 표는 제거했습니다.

추론 서버와 API 키 없이 Web Worker에서 Tesseract 한국어/영어 OCR 및 학습한 강의실 ONNX 모델을 실행합니다. 과목명 OCR에는 오류가 남아 있으므로 검토가 필요합니다. 모델은 인식 실행 시 불러오며 전체 정적 OCR 자산은 약 68MB입니다. 실제 다운로드는 캐시와 사용되는 코어에 따라 달라집니다.

모델 설치: `npm run setup:ocr` (빌드 전에 자동 실행). `src/lib/timetable-ocr/assets.json`의 SHA-256과 크기를 검사합니다. 모델 바이너리는 Git에서 제외하고 빌드 시 같은 출처에서 준비합니다. 테스트: `npm test`, 빌드: `npm run build`.

인식 엔진 출처와 라이선스는 `src/lib/timetable-ocr/README.md` 및 `public/licenses/timetable-ocr/`를 참고하세요. 사용자 사진은 저장소·배포 파일에 포함하지 않습니다.

## 원본 화질 자동 기본값

배경을 선택하면 화질은 기본적으로 `원본 화질`이며 실제 원본 크기로 출력합니다. FHD 기준 요일·시간/강의명/강의실 글씨는 18/20/15px이고, 원본에 FHD를 맞춰 넣는 배율(min(width/1920, height/1080))로 확대합니다. 예: UHD는 36/40/30px, 8K는 72/80/60px입니다. 가로/세로 크기는 39%/77%이므로 실제 픽셀 크기도 원본에 비례합니다. FHD/QHD/UHD를 직접 선택하면 각 출력 크기에 맞는 기본값으로 바뀝니다.

라이선스 원문은 `public/licenses/`와 빌드의 `dist/licenses/`에 포함됩니다. `npm run licenses:generate`로 설치된 의존성의 고지를 재생성하며, 빌드에서도 자동 실행합니다.
